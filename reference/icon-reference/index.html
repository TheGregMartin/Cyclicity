Story icons

These icons on the board correspond to various storylines; cards from those storylines will be placed upon the board in the spot with the corresponding icons.

Objective card icons

  • Priority: Each Classified Polity Objective card has 1-3 Priority icons on it, and each polity Supply Contracts card has 0–3 Priority icons on it. Each player’s choice of three objectives per game will have a total of 6 Priority icons among them (if possible).
  • Duration: Classified Polity Objectives with this icon are related to the duration of branch point decisions or to the number of branch points per game.
  • Ranking: Classified Polity Objectives with this icon are related to ranking the six players with regard to some type(s) of asset.
  • Sliders: Classified Polity Objectives with this icon are related to the values of all sliders (as opposed to specified sliders).

Branch point icons

  • Months: The duration of the branch point outcome—the number of months that the months marker should be moved. Also important for Drone Recycling.
  • Installation: The installation that should be given to the Sponsor of the branch point decision.
  • Envelope: The envelope that should be opened as part of resolving the branch point decision.
  • Discovery: The Discovery that should be read aloud as part of resolving the branch point decision.

Timing icons (on rule cards and installations)

  • Start: This effect is triggered at the start of each game.
  • Immediate: This effect is triggered immediately when the icon is revealed, and never again thereafter.
  • Conditional: This effect is triggered every time certain conditions are satisfied.
  • Once: This effect can be voluntarily triggered, once per game, when certain conditions are satisfied.
  • End: This effect is triggered at the end of every game.
  • Stage transition: This effect is triggered at every stage transition (which will be explicitly mentioned when relevant).
