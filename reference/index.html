Adjust PPGP

Terminology: PPGP stands for Polity Population Genetic Profile, EGO stands for Essential Genome Offset, EGG stands for Essential Genome Gradient (in case I want one term for player-vs.-baseline and another term for player-vs.-player). The four categories of essential genes are Complementary, Duplicate, Fungible, and Polymeric.

  • When taking this action, choose one gene type currently at 25% or more and one gene type currently at 25% or less. Add 1% to the higher gene type by filling in the box above the highest box already filled; and subtract 1% from the lower gene type by filling in the box below the lowest box already filled.
    • Once a gene type’s percentage is increased above 25%, it can never be reduced; and once a gene type’s percentage is reduced below 25%, it can never be increased. That’s not a problem though—there will never be a reason or incentive to both increase and reduce the same gene type. (Trust your polity’s central genetic planners!)
  • In addition to the single drone (which must remain on the PPGP mat until the end of the game), this action also requires double-marking a certain number of single-marked boxes in the grid (always starting from the top row of the grid, from left to right).
    • The number of single-marked boxes that must be double-marked is the new percentage of the higher gene type minus the new percentage of the lower gene type. For example, if the higher gene type is increasing from 27% to 28% and the lower gene type is decreasing from 24% to 23%, the number of boxes that must be double-marked is 28 – 23 = 5.
    • If there are not enough single-marked boxes in the grid, this action cannot be taken.
  • Adjusting PPGP is the only thing that double-marking boxes will be used for, so there’s no need to ration them or hold back.
