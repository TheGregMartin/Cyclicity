Tutorial branch points #7–8

This portion of the tutorial uses the branch point cards U.1 and U.2.

  1. Greg: Let’s see what envelope U has in store for us…. It starts by saying that the player with the fewest installations gains installation 18. If there’s a tie for fewest installations, the Patent Agent decides the tie.
  2. [the players figure out who gets installation 18]
  3. Greg: Interestingly, this installation has an associated rule card with the same number. This happens when the effect of the installation is a little too complicated to explain with icons alone.
  4. [whichever player got installation 18 reads its rule card aloud]
  5. Greg: Next it says to move the months marker to spot #116, and to put this deck of “sunspot cards” on the board. In a normal game, this deck would be placed here at the start. Let’s learn how the sunspot cards determine when the game ends.
  6. Greg: The sunspot deck consists of six Intensifying Sunspots cards placed on top of six Critical Sunspots cards. Within the Intensifying Sunspots cards, one of the six triggers the transition to the Critical Sunspots cards; within the Critical Sunspots cards, one of the six announces the end of the game.
  7. Greg: Every time the months marker crosses one of these red lines, moving to a higher orange row of the month tracker, we turn over the top card of the sunspot deck, placing it right below the red line that was crossed. In this case, placing the months marker at #116 made it cross two red lines, so we reveal two Intensifying Sunspots cards.
  8. Greg: As you see, neither one was the special card, so the sunspots are still “merely” intensifying.
  9. Greg: The last instruction from envelope U is to use these two cards as the new branch point deck, doing them in order. So let’s use the top card for the 7th branch point of this tutorial.
  10. [Greg reads the branch point setup aloud, and the players play through the vote and resolve its outcome’s effects, saving the sunspot cards for last]
  11. Greg: Now that the branch point outcome has been fully processed, we come back to the sunspot cards. The months marker crossed three red lines, so we’re going to turn over three of them.
  12. Greg: The first one is neutral; but the second one evelates the sunspots from Intensifying to Critical. When this happens, we set aside any remaining Intensifying Sunspots cards and continue immediately with Critical Sunspots cards. The last card drawn is neutral, so the game continues for now with another card from the branch point deck.
  13. [Greg reads the next branch point setup aloud, and the players play through the vote and resolve its outcome’s effects, saving the sunspot cards for last]
  14. Greg: Note that this branch point outcome triggers both Graham’s installation 6E and [someone’s] installation 43.
  15. Greg: The months marker crossed a lot of red lines, so this solar cycle is looking pretty bleak … and indeed, there’s the card announcing that the sunspots have escalated to Devastating, ending the solar cycle and the game.
