Start of every game after the first

Board setup

  • Place the months marker on the 0 spot on the marker track
  • Shuffle the 6 Critical Sunspots cards face down, then place them at the top of the month tracker. Do the same with the Intensifying Sunspots cards, putting them on top of the Critical Sunspots cards.
  • Place sliders on 5/4/3/2/1/0, in the order they finished last game. Sliders start with momentum 0 (no momentum markers) unless otherwise specified.
  • Set up all previously revealed cards in their spots on the board.

Player setup

  • All players set up their installations on their installation mat. Remember, each installation must remain in its zone, and all installations must be as far left as possible. (The order of installations within a zone is not important.)
  • Go through all start-of-solar-cycle triggers (including claiming drones and supply ships)
    • if order ever matters: story rules top to bottom, then top slider rules left to right (except whole new game-start envelopes) and then bottom slider rules left to right, then player rules clockwise starting with Sponsor
    • return 1st/2nd/etc. cards
  • If any game-start envelope was placed last game, open it now.

Draft objectives

Same as in the first game.

Finishing touches

  • The player with the Network Outage card places it on a valid rule card, one with the outage icon at the bottom. This is the first bribable action of the game.
  • Sponsor reveals the first branch point card, and we’re off!
