Each branch point

Whenever a game is in progress and no other actions are pending, players should draw a card from the shuffled branch point deck. If the card is a branch point card, go through the following phases in order:

  • Resolve the branch point decision
  • Remove drones
  • Process the branch point outcome

If the card is not a branch point card, follow its instructions.
