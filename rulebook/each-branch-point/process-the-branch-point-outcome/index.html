Process the branch point outcome

Flip over the branch point card, in the orientation appropriate to the decision voted by the players. The Sponsor reads the outcome text aloud.

Advance the months counter the number of months shown in the branch point outcome. Each player checks the visible portion of their Drone Recycling row for that number; if it is present, that player gains a drone from their reserve.

  • Even if some game effect modifies the number of months the counter moves, it is the actual number printed on the card that is relevant for Drone Recycling.

For any slider whose icon is present in the branch point outcome, increase that slider the indicated amount. If that slider had positive momentum before being moved up, increase its value +1 more than the indicated amount (the additional amount is +1 regardless of whether the positive momentum was +1 or +2). Sliders cannot go above 16 in any circumstance.

Set the momentum of any slider increased by the branch point outcome to +2. Reduce the momentum of every other slider by –1. For any other slider whose momentum was already at –2, decrease the slider value itself by –1 rather than reducing its momentum. Sliders cannot go below 0 in any circumstance.

If the branch point outcome has an installation icon, give the indicated installation to the Sponsor, who places it legally on their installation mat.

  • If a Sponsor ever receives an installation but their installation mat has no room for it, they must auction the new installation off to the highest bidder. The Sponsor decides any ties in this auction.
If the branch point outcome has a discovery icon, write its letter on the Discovery Tracker card, and read the text of the discovery aloud.

If the branch point outcome has an envelope icon, open the indicated envelope and follow its directions. Typically these will consist of the following:

  • Read a story card aloud, then place it on top of the indicated story slot on the board.
  • Replace the rule card from that story slot with a new one from the envelope.
  • Give the Sponsor the installation with number matching the envelope number, possibly with an associated installation rule card.
  • Shuffle branch point cards from the envelope into the branch point deck.

After the icons in the branch point outcome have been processed in this way, discard the branch point card. At this point, for each red line that the months marker crossed, place a sunspot card face up so that its top is aligned with the red line, going from bottom to top.

  • At first, turn over Intensifying Sunspots cards one by one.
  • As soon as the “Sunspot activity now Critical” card is revealed, discard any remaining Intensifying Sunspots cards.
  • Thereafter (starting immediately if any red lines remain) turn over Critical Sunspots cards one by one.
  • If the “Sunspot activity now Devastating” card is revealed, the game ends immediately (no other sunspot cards need to be turned over).

If the end of the game was not triggered, draw a new card from the branch point deck and continue playing.
