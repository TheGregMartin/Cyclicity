Prepare for next game

First, remove from the game all branch point cards revealed during the solar cycle.

If any special cards were drawn and not discarded, shuffle them back into the branch point deck.

Set the sliders to their starting values for the next game:

  • Each slider will take a distinct value in the range 1–6.
  • The highest slider at the end of this game will start at 6 for the next game; the second-highest slider will start at 5; and so on, with the lowest slider at the end of this game starting at 1 for the next game.
  • Ties between sliders’ ending values are broken by momentum. If a tie persists, break ties left (higher) to right (lower).

Shuffle the remaining 11 Classified Polity Objective cards (two from every player, minus the one chosen as the next game’s Objecture Rule card) back into the Classified Polity Objective deck.

Finally, resolve the Counter Processing card (even if it has been removed):

  • If the leftmost Stage Counter card has an empty spot to its left, place that card's Preliminary Envelope on that empty spot (that envelope will be opened at the start of the next game).
  • If the leftmost Stage Counter card has all its boxes marked, activate the Consequence Envelope(s) of that Stage Counter card, and remove that Stage Counter card from the game.
    • One Consequence Envelope will be opened at the start of the next game.
    • There might also be a Consequence Envelope to open right away, which will lead to some sort of event for the players. If necessary due to real-life time constraints, this event can be postponed to take place at the beginning of the next play session.
